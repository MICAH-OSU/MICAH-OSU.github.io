# micah-osu.github.io

Source for my portfolio site: https://micah-osu.github.io/

Plain HTML and CSS, no build step. GitHub Pages serves `index.html` from the `main` branch.

## Update

Edit `index.html` (content) or `style.css` (design), commit and push. The site updates within a minute or two.

To add a project, copy one of the `<article class="project">` blocks in `index.html`. For a screenshot, put the image in `images/` and add an `<a class="project-shot">` block like the Exercise Tracker one.
