CS 340 · Introduction to Databases · Fall 2026

Workout City Fitness Database

A relational database for a fitness studio that tracks customers, trainers, studios, classes and class bookings. Built as a two-person team project, from the entity-relationship design through normalization to a working Python application.

  • MySQL schema with five tables, including a many-to-many booking table that blocks double-booking
  • DDL and sample data scripts, plus DML queries for every table
  • Python application class that enforces business rules such as class capacity, with a command-line menu on top
  • Team workflow with Git branches and pull requests

Exercise Tracker

A full-stack app for logging workouts: create, view, edit and delete exercises. The React front end can run against the Express and MongoDB API, or entirely in the browser, which is how the live demo runs on GitHub Pages.

  • REST API with request validation and proper status codes
  • Two interchangeable data layers behind one interface, chosen at build time
  • Shared form component, inline validation messages and accessible controls
  • Automatic deployment with GitHub Actions
